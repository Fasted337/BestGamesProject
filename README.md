# BestGames — маркетплейс компьютерных игр

Многостраничный сайт (7 страниц) с адаптивной версткой.

🔗 **Демо:** https://bestgames.potapovt60045.workers.dev/

## Что внутри:
- Главная страница со слайдером (на чистом CSS)
- Каталог игр с фильтрами (мобильная версия — бургер-меню)
- Карточка игры
- Личный кабинет с историей покупок
- Формы регистрации и авторизации
- Административная панель (добавление и редактирование игр)
- Полностью адаптивный дизайн (десктоп, планшет, мобилка)

## Технологии:
- HTML5
- CSS3 (Flexbox, Grid, медиазапросы)
- Без использования JavaScript-фреймворков и библиотек
- Чистый CSS для интерактивных элементов (бургер-меню, модальные окна, слайдер)
